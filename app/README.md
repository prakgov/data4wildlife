# Instructions

Run everything from this `app/` folder:

1. `pip install -r requirements.txt`
2. Add the RapidAPI key and hashtags at the top of `fetch_hashtag_posts.py`, then run `python fetch_hashtag_posts.py`. Posts and images are saved to `hashtags/<hashtag>/`.
3. Open `index.html` in a browser (tested on Chrome) and import `hashtags/<hashtag>/<hashtag>-page01.json` to review posts.

For full instructions open "index.html" in an internet browser.
